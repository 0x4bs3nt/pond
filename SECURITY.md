# Security policy

## Report a vulnerability

Please report suspected vulnerabilities through [GitHub's private vulnerability reporting form](https://github.com/0x4bs3nt/pond/security/advisories/new). You can also open the repository's Security tab and select **Report a vulnerability**.

Do not publish vulnerability details in public issues or pull requests. Include:

- The affected version or commit.
- Steps to reproduce and a minimal proof of concept, if available.
- The potential impact and any prerequisites for exploitation.
- Relevant operating system, Bun, terminal, and database versions.

Use synthetic data and remove credentials, connection strings containing secrets, and private database contents from examples and logs.

If private reporting is unavailable, open an issue asking for a private security contact without including vulnerability details. Please coordinate public disclosure with the maintainer through the private report.
